Privacy Policy

Last updated: October 27, 2026

Ezra Creator Tools is a publishing tool for TikTok creators, operated by Guangyi Zhao. Creators sign in with their own TikTok account and use the tool to publish their own original videos to their own TikTok account through TikTok's official Content Posting API.

What data the tool handles

When a creator authorizes the tool, TikTok issues an OAuth access token and refresh token for that creator's own account, together with the creator's basic public account information (such as their TikTok user ID and display name) needed to confirm which account was authorized. Tokens are stored only on the creator's own computer, in a file readable only by the creator. The tool does not collect, store, or process any other person's personal data. It does not read TikTok messages, contacts, or browsing data.

How data is used

Tokens and account information are used for one purpose only: uploading and publishing the creator's own video files to the creator's own TikTok account, and checking the publishing status of those uploads.

Sharing

No data is sold, rented, or shared with any third party. The only external service the tool communicates with is TikTok's official API.

Retention and deletion

Any creator can revoke the tool's access at any time in their TikTok account settings (Settings and privacy > Manage apps), and can delete the local token file to erase all stored data immediately.
