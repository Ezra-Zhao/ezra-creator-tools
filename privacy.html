Privacy Policy

Last updated: October 12, 2026

Ezra Creator Tools is a personal software tool operated by Guangyi Zhao. It is used by its owner to publish his own original videos to his own TikTok account through TikTok's official Content Posting API.

What data the tool handles

The tool stores the TikTok OAuth access token and refresh token that TikTok issues when the account owner authorizes the tool. Tokens are stored only on the owner's own computer, in a file readable only by the owner. The tool does not collect, store, or process any other person's personal data. It does not read TikTok messages, contacts, or browsing data.

How data is used

Tokens are used for one purpose only: uploading and publishing the owner's own video files to the owner's own TikTok account, and checking the publishing status of those uploads.

Sharing

No data is sold, rented, or shared with any third party. The only external service the tool communicates with is TikTok's official API.

Retention and deletion

The owner can revoke the tool's access at any time in TikTok account settings (Settings and privacy > Manage apps), and can delete the local token file to erase all stored data immediately.
